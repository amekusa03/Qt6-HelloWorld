## English

A minimal "Hello World" desktop application built with Qt 6 (C++ & QML).

This sample demonstrates a basic desktop window displaying `Hello World` built using Qt Creator.

- **Target Platform**: Linux (Tested on Ubuntu)
- **Environment**: Qt Creator & Qt 6.x
- **Repository**: [https://github.com/amekusa03/Qt6-HelloWorld](https://github.com/amekusa03/Qt6-HelloWorld)

### 📖 Article (Japanese)

- [Qiita Article: Getting Started with Qt 6](https://qiita.com/amekusa03/items/79fe702be160c37c06c8)

[![Video Overview](https://img.youtube.com/vi/v86BQykeWFY/maxresdefault.jpg)](https://youtu.be/v86BQykeWFY?si=ZmMB2RJrHV_AEl-Z)

### 🛠 Getting Started

1. Install Qt Creator and Qt 6 (e.g., Qt 6.x).
2. Clone this repository:

```bash
git clone https://github.com/amekusa03/Qt6-HelloWorld.git
cd Qt6-HelloWorld
```

3. Open `CMakeLists.txt` in Qt Creator and configure the project build.
4. Run the Debug or Release build. A window will open displaying "Hello World".

### 📦 Dependencies

- Qt 6 (Core, Quick, Qml)
- CMake & C++ compiler (GCC/Clang)
